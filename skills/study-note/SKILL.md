# Study note

The notes folder is in the CLAUDE.md study-loop block.

1. **Covered already?** Read the folder's `Overview - *.md`. If yes: short refresher + link, or
   extend that note with what's genuinely new.
2. **Write** one file. Frontmatter `type: concept`, `topic`, `project`, `updated`, `tags`. Title =
   the concept, not the episode. Sections: *The idea in two sentences* · *How it works* (numbered
   flow) · *In this project* (real files/functions) · *Pitfalls* · *Related* (`[[wikilinks]]`).
   Examples minimal and runnable.
3. **Register** it as one line in the overview note (create it if missing: a numbered reading order).
4. Let the user read and ask before code or cards follow. Cards come later, from confirmed code.
